# GTM positioning

## What we sell today

**Agentic fraud investigation for complex lending** — not a full LOS or credit memo factory.

Pillars buyers can demo this week:

1. Cross-document contradiction detection with citations
2. Dynamic bank-policy RAG (ingest without code deploys)
3. Hybrid OSINT entity profiling (registry, employer, sanctions, web, address) → auditable case file

Recommendation (`approve` / `review` / `decline`) is **advisory**. Underwriter remains decision-maker.

## ICP

- Specialty / community lenders running SBA 7(a), CRE acquisition, or bank-statement mortgages
- Fraud / credit risk ops teams drowning in unstructured packets
- Buyers who already have LOS + spreading tools but lack investigation automation

## Competitive wedge

| Alternative | Gap we fill |
|-------------|-------------|
| Manual underwriter checklist | Scale + audit trail across docs |
| Generic LLM chat on PDFs | Vertical packs, policy RAG, structured case file |
| Point KYC APIs alone | Cross-document narrative + policy + OSINT fused |

## What not to claim in sales

- “Replaces underwriters”
- “Full underwriting suite” (spreading / memo / LOS)
- “Enterprise KYC coverage” without contracted data vendors
- Production accuracy equal to golden-set fixture metrics ([OSINT_EVAL.md](OSINT_EVAL.md) disclaimer)
